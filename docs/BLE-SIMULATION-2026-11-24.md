# 2026-11-24 Edge 发送模拟记录

## 模拟范围

独立无头 Edge 158.0.4370.33 中加载实际 `js/ble.js`，以 JavaScript 外围设备模拟器替代实体卡片。模拟器为控制指令注入 `NetworkError: Connection already in progress.`，并严格验证控制指令顺序、长度、数据包序号、每个 payload 字节、补零、逐块回执和最终 `05 08`。

此环境未使用 Windows 实体蓝牙适配器和卡片。注入错误用于复现日志对应的程序路径，不能证明实体故障的底层原因，也不能代替硬件传输测试。

## 结果

统一 payload 长度 24,686 字节，内容为确定性字节序列，补齐至 24,720 字节；103 个包，每包 4 字节小端序号 + 240 字节内容。模拟器每 16 包返回逐块回执，最后返回完成通知。

| 场景 | 结果 |
|---|---|
| 旧版 b，第一次 `01` 控制写入报告 busy | 与用户日志一致：请求分块大小后抛错，数据包数 0 |
| 修复版 c，`01` 先拒绝两次 | 有限退避后完成，103 包校验通过，收到 `05 08` |
| 修复版 c，`02` 先拒绝两次 | 有限退避后完成，103 包校验通过，收到 `05 08` |
| 控制特征只声明 writeWithoutResponse | 选择对应写入接口，103 包校验通过 |

旧版与修复版使用相同握手字节：`01`、`02 90 60 00`、`03`。图片编码、压缩、映射及分包格式未改动。新版按控制特征声明选择现代写入接口；`01`、`02` 遇到 busy 时有限重试，`03` 出错直接停止，避免重复启动。

Node 回归测试另外覆盖：控制写入一直 busy 时的次数限制、清理和明确报错；开始传输失败不重复启动；完整图像恢复重建；连接、服务发现、特征、通知、多标签互斥及缓存。
